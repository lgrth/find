## 2. ข้อมูลในชีต — คอลัมน์ `Note1`–`Note5` ใน Sheet 1

เพิ่มคอลัมน์ `NoteN` **ถัดจาก `ValueN`** ของแต่ละสกิล (5 คอลัมน์) แล้วเขียนเงื่อนไข**ตามข้อความในเกม**

| ID | Substat1 | Value1 | Note1 | Substat2 | Value2 | Note2 | Substat3 | Value3 | Note3 | Substat4 | Value4 | Note4 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| [ไวท์] เรดมอนสเตอร์พิโรธ | แปลน 3 หลัง | 80 | หลัง 2 เทิร์น ลดลง -50% | ป้องกันบังคับย้ายและดักจับ | 70 | จำกัด 2 ครั้ง | ป้องกันเอฟเฟคอันตราย | 65 | | กันวิคตอรี่ | 95 | จำกัด 1 ครั้ง |
| [ไวท์] แกนบลัดกักขังโกสต์ | ขังคุก | 45 | +5% เมื่อไม่แสดงผล | เดินไดเมนชั่น | 60 | | ป้องกันเคลื่อนย้ายอัญเชิญ | 45 | | ป้องกันบังคับย้ายและดักจับ | 90 | 2 ครั้ง |

- จี้ปกติ / สกิลปกติ = เว้น Note ว่าง (ส่วนใหญ่ของชีต)
- **ห้ามเขียนข้อความลงในช่อง `Value`** — คอลัมน์ Value เป็นตัวเลข ถ้ามีข้อความปน Google จะส่งช่องนั้นมาเป็นค่าว่าง (ค่าหาย) · เพราะเหตุนี้จึงแยกเป็นคอลัมน์ Note
- เว็บอ่านคอลัมน์จาก**ชื่อหัวคอลัมน์** จึงแทรกคอลัมน์ได้ · โค้ดจะเพิ่ม `headers=1` ตอนโหลดแท็บจี้ ให้อ่านหัวคอลัมน์ได้แน่นอน (ตอนนี้ปล่อยให้ Google เดา)

รูปแบบข้อความที่เว็บอ่านได้ (เขียนหลายอย่างในช่องเดียวได้ คั่นด้วย `,`):

| เขียนว่า | ได้ | ตัวอย่าง |
|---|---|---|
| `+X% เมื่อไม่แสดงผล` | 📈 grow = X | `+5% เมื่อไม่แสดงผล` |
| `หลัง N เทิร์น ลดลง -X%` | 📉 decay = X หลังเทิร์น N | `หลัง 2 เทิร์น ลดลง -50%` |
| `จำกัด N ครั้ง` หรือ `N ครั้ง` | 🔒 limit = N | `จำกัด 2 ครั้ง`, `2 ครั้ง` |

- ช่องว่าง / `%` / เครื่องหมายลบ ไม่บังคับ
- ข้อความที่อ่านไม่ออก → เตือนใน console (แถว + จี้ + ข้อความ) และ tooltip แสดงข้อความนั้นตรง ๆ คะแนนไม่เปลี่ยน
- แท็บ Abilities **ไม่ต้องเพิ่มคอลัมน์**

ตรวจข้อมูล (เตือนใน console):
- Note ที่ไม่มีสกิล (SubstatN ว่าง) · ข้อความอ่านไม่ออก
- 📈/📉 กับสกิล `unit = amount` (ออกแบบไว้สำหรับโอกาสเท่านั้น)
- มีทั้ง 📈 และ 📉 ในช่องเดียว (ยังไม่กำหนดว่าคิดยังไง → ใช้แค่ 📉)

## 3. คำนวณ (`js/search-core.js`)

แต่ละ substat ของจี้ได้ข้อมูลเพิ่ม `{ name, value, grow?, decay?, decayAfter?, limit?, note? }` · เพิ่ม `effectiveValue(substat)` แล้วให้ `jewelToCandidate` ใช้ค่านี้แทน `value` ก่อนส่งเข้า `abilityScore` (รวมถึงกรณีเลือกทั้งกลุ่ม ที่ใช้ "ค่าสูงสุดในกลุ่ม")

### 3.1 📈 เติบโตเมื่อไม่แสดงผล
โอกาสเทิร์นที่ k หลังออกครั้งล่าสุด: `pₖ = min(100, p₀ + k·grow)`
จำนวนเทิร์นเฉลี่ยต่อการออก 1 ครั้ง: `E = Σₖ Πⱼ<ₖ (1 − pⱼ/100)` → **โอกาสเฉลี่ย = 100 / E**
(ไม่ขึ้นกับความยาวเกม · `pₖ` ถึง 100 แล้วผลรวมหยุดเอง)

| ค่าเริ่ม | grow | ใช้คิดคะแนน |
|---|---|---|
| 45% (ขังคุก) | +5 | **49.4** |
| 10% | +5 | 22.1 |
| 30% | +5 | 36.9 |
| 60% | +5 | 62.7 |
| 45% | 0 | 45.0 (เท่าเดิม) |

### 3.2 📉 ลดลงหลัง N เทิร์น
ใช้คิดคะแนน = `max(0, value − decay)` → แปลน 3 หลัง 80% −50 = **30**

### 3.3 🔒 จำกัดครั้ง
ไม่เปลี่ยนคะแนน

### 3.4 ผลต่อผลค้นหา
- คะแนนเป็นตัวตัดสิน**ลำดับสุดท้าย** (ขาดน้อย → ไม่ต้องการน้อย → แถมมาก → คะแนน) → จำนวนสกิลที่ตรงไม่เปลี่ยน · เปลี่ยนแค่ลำดับระหว่างเซ็ตที่เสมอกัน และตัวเลข "คะแนนความเทพ"
- การคัดจี้ตัวแทนต่อ mask (`PER_MASK`) ใช้คะแนนเป็นตัวตัดสินสุดท้ายเช่นกัน → จี้ที่ถูกเลือกเป็นตัวแทนอาจเปลี่ยนบ้าง
- golden ที่คาดว่าเปลี่ยน: สถานการณ์ที่มี ขังคุก / แปลน 3 หลัง (ตัวเลขคะแนน + ลำดับบางส่วน) → อธิบายใน commit

## 5. รวมชื่อที่มี "ครั้ง" กลับเป็นชื่อหลัก (G9)

| ชื่อในชีตตอนนี้ | จี้ | ชื่อหลัก | Note |
|---|---|---|---|
| `ยกเลิกขังคุกทันที (2 ครั้ง)` | 8 | `ยกเลิกขังคุกทันที` | `2 ครั้ง` |
| `ป้องกันเอฟเฟคอันตราย (จำกัดครั้ง)` | 5 | เก็บชื่อแยก (ตัดสินไว้) **หรือ** `ป้องกันเอฟเฟคอันตราย` (Q2) | `จำกัด N ครั้ง` |

ขั้นตอน (ต่อ 1 ชื่อ):
1. Sheet 1: เปลี่ยนชื่อใน SubstatN เป็นชื่อหลัก และเขียนจำนวนครั้งใน NoteN
2. แท็บ Abilities: ลบแถวชื่อเดิม · ใส่ชื่อเดิมในคอลัมน์ใหม่ `old_names` ของแถวชื่อหลัก (คั่นด้วย `,`)
3. เว็บ: ลิงก์แชร์ / Filter ที่บันทึกที่มีชื่อเดิม → แปลงเป็นชื่อหลักอัตโนมัติผ่าน `old_names`

ผลข้างเคียงของการรวม: 2 แบบกลายเป็นสกิลเดียวกัน → **ใส่คู่ในเซ็ตเดียวไม่ได้** และค้นหาเจอรวมกัน

คอลัมน์ `old_names` ใช้ซ้ำได้กับเฟส 6 ของแผนกลุ่ม (แยกชื่อตามการแสดงผล) — แทนการเดาจากวงเล็บ
